# Milestone audit: six-host plugin work

Audited at commit 5f76f14 on branch plugin-core-slice (PR #89), then re-checked at 611e926 (PR #91) with the AC3/AC5 reconciliation in PR #95. This supersedes the audit written at ab6fcf9. Each criterion lists the verdict and the evidence it rests on. A criterion passes only when the evidence in the repo or a recorded CI run shows it.

Overall verdict: **not complete**. AC4 passes on the verified live evidence. AC5 is downgraded to **Partial** in this PR (it was Pass before), and AC3, AC6, and AC9 are **Partial**, and AC10 is **Fail**, with their limits recorded per row: minimum host versions are not documented by any host, Prime-Agent's install is not verified, no adapter-level test runs a flag-false case end to end, and the credential scanner does not cover unquoted values. Live results for all six hosts are in `docs/validation/results/`.

## Changes since ab6fcf9

- Cursor removed from the six-host set.
- Adapter CLI `bin/ultrathink-adapter` added: pass-through arguments and `--raw`. Raw output is the full child stdout; the 4096-character cap applies only to the JSON envelope.
- Hermes, Prime-Agent, and Claude Code command surfaces route through the CLI. Hermes errors now read "command failed" (accepted).
- Prime-Agent runs with ULTRATHINK_HOST=prime-agent; its state directory was checked read-only.

## Open decisions and limits

- Live validation: AC4 complete. AC5 is Partial because Prime-Agent's install is not verified (`docs/validation/results/prime-agent.md`). Its install `<source>` syntax needs an owner decision and a live run that is recorded in the repo.
- Prime-Agent and Grok Build: unmapped by design.
- Minimum supported host versions: not documented by any host, and no floor is a validated minimum. Per-host status is in docs/validation/results/minimum-host-versions.md.
- Hermes private import: hosts/hermes/bridge.py reads `_resolve_hook_callback_timeout` from hermes_cli.plugins. No public equivalent exists in v0.23.1.
