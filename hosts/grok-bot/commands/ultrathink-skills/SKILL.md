# /ultrathink-skills

This command manages skills that ultrathink generated on a local machine, and it runs on Claude Code only. In this conversation there is no store for generated skills, so there is nothing to list, disable or delete here.

Tell the user: "/ultrathink-skills runs on Claude Code only. Run it there with the ultrathink plugin installed."

Do not list, disable or delete any skill. Do not plan this command. Do not invent a skill list, a file path, or an engine route. Do not write a file, do not run a hook, and do not run a planner.
